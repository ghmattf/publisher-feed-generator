# Publisher Feed Generator

WordPress plugin that lets labels, studios, engineers, hosts and artists build Podcasting 2.0 **publisher feeds**, download them to self-host, or sign in with a Nostr remote signer and have them hosted.

- Install: zip the `plugin/` folder (keep the folder name `msp-publisher-feeds` inside the zip), upload via Plugins > Add New, add `[msp_feed_generator]` to a page. Details in `plugin/readme.txt`.
- Develop: see `AGENTS.md`. Run checks with `tests/run-all.sh`.
